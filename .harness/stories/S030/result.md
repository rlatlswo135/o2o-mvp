# S030 — 새 디자인 기준과 인증 없이 확인하는 사장님 화면

## 한 일
- 코랄 살롱 방향의 색상·타이포·입력 크기·모서리·그림자 토큰을 정하고 공통 UI와 고객 화면에 적용했다.
- `/login`에 독립 로그인 화면을 만들었다. 실제 인증·전송·저장 없이 인증 연결 예정 상태로 제공한다.
- `/customers`에 공통 업무 레이아웃과 고객 nav를 적용하고 `/`에서 고객 화면으로 이동하도록 바꿨다. 인증 구현을 기다리지 않고 URL로 직접 확인할 수 있다.
- 고객 등록·수정을 모달 시트로 바꿔 목록 배치를 유지하고, 기존 서버 연결·오류 처리·저장 중 조작 제한·포커스 이동을 보존했다.
- 모바일·태블릿·데스크톱 레이아웃과 긴 고객 이름 표시를 정리했다.
- 공통 UI 검토용 첫 화면과 예시 전용 코드·테스트를 제거하고 실제 공통 UI·고객 기능의 테스트를 유지·보강했다.
- 오늘 예약은 디자인 시안으로만 다뤘으며 실제 예약 기능·인증·서버·공유 contract는 변경하지 않았다.

## 바뀐 파일
- `client/src/shared/ui/`: 디자인 토큰·공통 UI·모달 시트
- `client/src/shared/brand/brand.tsx`: 공통 브랜드 표시
- `client/src/routes/`: 로그인·공통 업무 레이아웃·고객 경로·첫 진입 처리, 검토 예시 제거
- `client/src/features/auth/login-page.tsx`: 로그인 화면
- `client/src/features/customers/`: 고객 목록·등록·수정 화면
- `client/src/styles.css`: 전역 폰트·배경·텍스트 스타일
