# S034 — 고객·시술을 연결한 예약 등록·조회·수정·취소 화면

## 한 일
- 업무 메뉴에 예약을 추가하고 `/reservations`에서 오늘과 선택 날짜의 예약을 시작 시각순으로 확인할 수 있게 했다. 날짜 이동·오늘 복귀·페이지 나눔과 취소 포함 조회를 제공한다.
- 기존 고객 1명·시술 1개를 선택해 예약을 등록하고 고객·시술·날짜·시간을 수정할 수 있게 했다. 한국 시간 기준으로 시술 소요시간에서 종료 일시를 계산하며, 기존 예약에 저장한 시술 정보·소요시간은 시술 재조회만으로 바뀌지 않는다.
- 예약 취소는 삭제 대신 원래 예약·취소 시각·선택 입력 사유를 보존한다. 취소된 예약은 기본 목록에서 제외하고 취소 포함 조회에서 기록을 확인할 수 있다.
- 필수값·날짜·시간 검증, 연속 제출 방지, 저장 실패 시 입력·기존 예약 유지, 조회 오류·재시도와 지연 응답에 의한 이전 데이터 복원 방지를 적용했다.
- 기존 공통 테이블과 시트를 활용해 등록·수정·취소 화면을 구성하고, 키보드·포커스 복귀·좁은 화면 대응과 예약 동작 테스트를 추가했다.
- 예약은 메뉴 이동 시 유지되고 새로고침 시 초기화되는 가상 저장으로 제공한다. 서버 미저장·중복 검사 미지원 안내를 표시하며, 홈·담당자·복수 시술·운영 규칙·서버/공유 계약은 변경하지 않았다.
