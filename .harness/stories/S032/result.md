# S032 — 시술 관리 페이지와 시술 등록 FE

## 한 일
- 사장님 메뉴에 시술 페이지(`/treatments`)를 추가하고 시술명·기본 소요시간·기본 가격과 전체 건수를 목록으로 표시했다.
- 기존 고객 화면과 같은 등록 시트를 사용해 시술을 등록하고 목록 맨 위에 반영하도록 했다. 데스크톱은 오른쪽, 모바일은 아래쪽에서 열린다.
- 시술명 필수·공백 정리, 분 단위 양의 정수 소요시간, 원 단위 0 이상 정수 가격을 확인하며 입력 오류를 필드 가까이에 표시한다. 0원 시술도 등록할 수 있다.
- 저장 중 입력·닫기·중복 제출을 막고, 실패하면 시트 안에 알림을 표시하며 입력을 유지해 재시도할 수 있게 했다. 성공하면 시트를 닫고 결과를 알린다.
- 목록의 로딩·빈 결과·조회 실패·재조회 실패와 다시 시도를 제공하고, 등록·오류·목록 반영의 회귀 테스트를 추가했다.
- 예시 시술과 앱 메모리의 가상 데이터를 사용한다. 메뉴를 이동해도 등록 항목은 유지되지만 새로고침하면 초기화되며, 이 제한을 화면에 안내한다. 서버·DB·공유 API 계약은 변경하지 않았고 실제 저장 기능은 연결하지 않았다. 수정·삭제·비활성화와 예약 연동은 포함하지 않았다.
